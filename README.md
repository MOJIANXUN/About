# 莫简荨 · 个人主页

> 一个响应式个人主页 / 在线简历网站，展示个人简介、经历、技能、作品与联系方式。

## 预览

在线访问：**[GitHub Pages](https://mojianxun.github.io/About/)**

## 功能模块

- 🏠 **简介** — 个人信息与头像
- 👤 **关于** — 背景介绍
- 📋 **经历** — 工作/学习经历时间线
- ⚡ **技能** — 技能与熟练度
- 🎨 **作品** — 项目作品展示
- 📝 **案例** — 博客/案例文章
- ✉️ **联系** — 联系方式与表单

## 技术栈

- HTML5 + CSS3
- Bootstrap 响应式布局
- jQuery
- 粒子背景动画（Canvas）
- 页面滚动动画（wow.js / animate.css）

## 本地运行

```bash
git clone git@github.com:MOJIANXUN/About.git
cd About
# 直接用浏览器打开 index.html 即可
```

## 项目结构

```
About/
├── index.html          # 主页面
├── css/                # 样式文件
├── js/                 # 脚本文件
├── images/             # 图片资源
├── fonts/              # 字体图标
└── .github/workflows/  # GitHub Pages 部署
```
